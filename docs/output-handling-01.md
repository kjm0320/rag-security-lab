\# HTML 보고서 출력 처리 검증



\## 목적



모델 응답을 포함한 JSON 보고서를 HTML로 변환할 때,

입력 내용이 실행 가능한 HTML로 해석되는 것을 방지한다.



\## 구현



\- JSON 전체를 직렬화한 후 HTML 이스케이프 적용

\- 변환된 내용을 pre 요소 안에 텍스트로 표시

\- JSON의 값뿐 아니라 키에도 같은 처리 적용

\- CSP로 스크립트와 외부 리소스 등을 추가 제한

\- 입력 파일과 출력 파일이 같으면 변환 거부



주된 방어는 HTML 텍스트 문맥에 맞춘 이스케이프다.

CSP는 추가 제한이다.



\## 자동 테스트



| 검증 대상 | 확인 내용 |

|---|---|

| script, img, 링크, pre 탈출 문자열 | 입력으로부터 해당 태그가 생성되지 않음 |

| JSON 키의 공격 문자열 | 키도 텍스트로 처리됨 |

| 한국어, 인용부호, 특수문자 | 원래 JSON 내용이 보존됨 |



표준 라이브러리 HTMLParser로 생성된 태그와 텍스트를 검사했다.

전체 프로젝트 자동 테스트 42개가 로컬에서 통과했다.



\## 수동 확인



기존 disclosure\_demo.json을 HTML로 변환하고,

생성된 보고서가 브라우저에서 열리는 것을 확인했다.



\## 검증 한계



\- 실제 브라우저에서 공격 실행 여부를 자동 검증하지는 않았다.

\- HTML 텍스트 문맥에 대한 처리다.

\- JavaScript, CSS, URL 문맥에 그대로 적용할 수 있는 방어는 아니다.

\- HTML 이스케이프는 민감정보를 제거하지 않는다.

\- 보고서에는 원본 모델 응답과 합성 비밀값이 포함될 수 있다.

\- 입력 데이터로부터 링크나 이미지를 생성하지 않는다.



\## 실행 방법



프로젝트 루트에서 실행한다.



```bat

python -m rag\_security\_lab.html\_report reports/disclosure\_demo.json

start "" "reports\\security\_report.html"

```



기본 출력 경로는 reports/security\_report.html이다.

같은 경로로 다시 실행하면 기존 HTML 파일을 덮어쓴다.



이 작업은 LLM API를 호출하지 않는다.

생성 보고서는 Git 추적에서 제외된다.
