\# 키워드·벡터 검색 품질 비교



\## 목적



표현이 다른 질문에서 정답 문서를 찾는 능력과,

접근 가능한 답변 근거가 없는 질문에서 빈 결과를 반환하는지 비교한다.



\## 조건



\- 문서: 공개 2개, 제한 1개

\- 모델: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2

\- FastEmbed: 0.8.0

\- ONNX Runtime: 1.30.0

\- 임베딩 계산: 로컬 CPU

\- 검색 결과 수: top\_k=1

\- 두 검색 방식 모두 역할별 접근 제어 적용

\- Gemini API 호출 없음



\## 초기 탐색 결과



search\_quality\_cases.json의 질문 8개를 사용했다.

정답 문서가 있는 질문 6개, 근거 없는 질문 2개다.



| 지표 | 키워드 | 벡터·임계값 0.0 |

|---|---:|---:|

| 정답 문서 1순위 검색 | 5/6 | 6/6 |

| 근거 없는 질문에서 빈 결과 | 2/2 | 0/2 |



벡터 검색에서 일반 사용자에게 제한 문서는 반환되지 않았다.

다만 관련성이 낮은 공개 문서가 반환됐다.



\## 임계값 선택



탐색 질문에서 관찰한 점수:



\- 정답 문서의 최저 점수: 0.4815

\- 근거 없는 질문에서 반환된 문서의 최고 점수: 0.1001



이 결과를 바탕으로 실험용 임계값을 0.3으로 선택했다.

보편적인 권장 임계값이나 다른 모델에 적용 가능한 값은 아니다.



\## 별도 검증 결과



임계값을 0.3으로 유지하고 search\_validation\_cases.json의

새로운 질문 8개를 평가했다.



| 지표 | 키워드 | 벡터·임계값 0.3 |

|---|---:|---:|

| 정답 문서 1순위 검색 | 4/6 | 6/6 |

| 근거 없는 질문에서 빈 결과 | 2/2 | 2/2 |



키워드 검색은 암호 길이와 비밀번호 변경 간격을 묻는 질문에서 실패했다.

벡터 검색은 해당 문서를 포함해 정답 문서 6개를 모두 1순위로 반환했다.



이번 검증 결과를 보고 임계값을 추가 조정하지 않았다.



\## 지표 정의



\- 정답 문서 1순위 검색: 첫 번째 검색 문서가 기대 문서 ID 중 하나인지 평가

\- 근거 없는 질문에서 빈 결과: 반환된 문서가 없는지 평가



검색 품질 지표이며 생성 답변의 정확성이나 보안성을 직접 평가하지 않는다.

관리자의 복구 코드 질문도 문서 검색 여부만 평가한다.

코드 출력 제한은 별도의 출력 필터 정책으로 처리한다.



\## 한계



\- 문서 3개와 조정용·검증용 질문 각각 8개에 한정된다.

\- 검증 질문도 같은 문서와 유사한 주제를 사용한다.

\- 독립적인 외부 벤치마크 결과가 아니다.

\- 더 긴 문서와 다양한 주제에 대한 평가가 필요하다.

\- 임계값 미달이 실제로 근거가 전혀 없다는 사실을 보장하지는 않는다.

\- 모델이나 문서 구성이 바뀌면 임계값을 다시 평가해야 한다.



\## 재현



초기 탐색:



```bat

python -m rag\_security\_lab.evaluate\_search --min-score 0.0 --output reports/search\_quality\_threshold\_0.json

```



선택한 임계값으로 별도 검증:



```bat

python -m rag\_security\_lab.evaluate\_search --cases datasets/search\_validation\_cases.json --min-score 0.3 --output reports/search\_validation\_threshold\_03.json

```
