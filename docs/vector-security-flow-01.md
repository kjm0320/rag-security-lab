\# 벡터 RAG 보안 흐름 회귀 테스트



\## 목적



벡터 RAG 경로에서 개별 보안 제어가 함께 동작하는지 확인한다.



\## 테스트 구성



실제 사용하는 구성:



\- 임시 SQLite 문서 저장소

\- 벡터 인덱스 저장·조회

\- 역할별 문서 접근 제어

\- 코사인 유사도와 임계값 처리

\- RAG CLI 입력 처리

\- 합성 비밀값 출력 필터



대체한 구성:



\- 임베딩 계산: 고정 벡터

\- Gemini 답변 생성: 가짜 응답

\- 환경 설정: 테스트용 값



실제 API 호출이나 모델 다운로드는 하지 않는다.

기존 로컬 DB와 실험 보고서를 변경하지 않는다.



\## 검증 결과



| 사례 | 확인 내용 |

|---|---|

| 공개 문서 질문 | 공개 문서만 생성 입력에 포함 |

| 일반 사용자의 제한 문서 질문 | 답변 생성 호출 생략 |

| 질문에서 관리자 역할 주장 | 실제 역할이 바뀌지 않으며 생성 호출 생략 |

| 관리자의 제한 문서 조회 | 문서는 전달하되 출력의 합성 비밀값은 가림 |

| 문서 변경 후 인덱스 미갱신 | 오류로 중단하고 생성 호출 생략 |



신규 테스트 5개를 포함한 전체 자동 테스트 84개가 로컬에서 통과했다.



\## 검증 범위와 한계



고정 벡터와 가짜 응답을 사용한 애플리케이션 흐름 검증이다.



실제 임베딩 모델의 의미 검색 정확도나

LLM의 프롬프트 인젝션 저항성을 평가한 것은 아니다.

역할은 실습용 CLI 값이며 실제 사용자 인증도 아니다.



오래된 인덱스는 거부하지만 자동으로 재생성하지는 않는다.
