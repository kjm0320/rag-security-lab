\# 로컬 벡터 검색 검증 01



\## 구현



\- 문서와 임베딩을 SQLite에 저장

\- 역할별 접근 권한으로 후보 문서를 먼저 제한

\- 접근 가능한 문서의 정규화 벡터와 질문 벡터의 내적 계산

\- 코사인 유사도 내림차순으로 결과 반환

\- 문서 내용·접근 등급 변경 시 오래된 벡터 사용 거부

\- 인덱스 모델 이름 불일치 시 검색 거부



SQLite에 벡터를 저장하고 Python에서 후보 전체를 비교하는

소규모 검색 구현이다. 대규모 전용 벡터 DB는 아니다.



\## 검증 환경



| 항목 | 값 |

|---|---|

| OS / 실행 환경 | Windows CMD / Python 3.12.10 |

| RAM | 8GB |

| 임베딩 실행 장치 | CPU |

| FastEmbed | 0.8.0 |

| ONNX Runtime | 1.30.0 |

| 모델 | sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 |

| 벡터 차원 | 384 |

| 배치 크기 | 1 |

| 스레드 설정 | 2 |



실행 시 이전 CLS 방식에서 mean pooling 방식으로 변경됐다는

라이브러리 경고가 표시됐다. 현재 설치 버전으로 인덱스를 생성하고 검색했다.



패키지 버전 또는 임베딩 설정이 바뀌면 인덱스를 다시 생성해야 한다.

현재 인덱스는 모델 이름과 문서 해시를 확인하지만,

패키지 버전·모델 파일 리비전·pooling 설정까지 검증하지는 않는다.



\## 의미 검색 관찰



질문:



> 암호는 얼마나 자주 바꿔야 하나요?



user 역할, top\_k=1로 검색한 결과:



| 순위 | 문서 | 코사인 유사도 |

|---|---|---:|

| 1 | doc-001 — 비밀번호 정책 | 0.7230 |



질문과 문서의 표현이 달라도 관련 문서가 검색된 사례다.

한 질문의 결과이며 전체 검색 품질을 입증하지는 않는다.



\## 역할별 검색 관찰



질문:



> 관리자 복구



| 역할 | 반환 문서 | 유사도 |

|---|---|---:|

| user | doc-002 — VPN 이용 안내 | 0.1001 |

| user | doc-001 — 비밀번호 정책 | 0.0984 |

| admin | doc-003 — 관리자 복구 절차 | 0.7053 |

| admin | doc-002 — VPN 이용 안내 | 0.1001 |

| admin | doc-001 — 비밀번호 정책 | 0.0984 |



일반 사용자에게 제한 문서 doc-003은 반환되지 않았다.

관리자에게는 해당 문서가 가장 높은 순위로 반환됐다.



기본 min\_score가 0.0이므로 관련성이 낮은 공개 문서도 반환됐다.

검색 결과 존재 여부만으로 답변 근거가 충분하다고 판단할 수 없다.



\## 자동 테스트



전체 프로젝트 테스트 67개가 로컬에서 통과했다.



벡터 저장소 테스트 7개는 고정된 가짜 임베딩으로 다음을 검증한다.



\- 유사도순 정렬

\- top\_k 선택 전 접근 제어

\- 임계값 미달 시 빈 결과

\- 변경된 문서의 오래된 벡터 거부

\- 다른 모델의 인덱스 거부

\- 잘못된 벡터로 재생성 시 기존 인덱스 보존

\- 잘못된 역할을 질문 임베딩 전에 거부



이 테스트는 실제 모델의 검색 품질을 평가하지 않는다.

모델 다운로드나 외부 LLM API 호출 없이 실행한다.



\## 실행 방법



선택 패키지 설치:



```bat

python -m pip install -e ".\[vector]"

```



문서 DB 초기화 및 벡터 생성:



```bat

python -m rag\_security\_lab.document\_store init

python -m rag\_security\_lab.vector\_store build

```



init은 DB의 문서 목록을 JSON 내용으로 교체한다.

build는 저장된 문서로 벡터 인덱스를 재생성한다.



검색:



```bat

python -m rag\_security\_lab.vector\_store search "암호는 얼마나 자주 바꿔야 하나요?" --role user --top-k 1

python -m rag\_security\_lab.vector\_store search "관리자 복구" --role user

python -m rag\_security\_lab.vector\_store search "관리자 복구" --role admin

```



모델 최초 다운로드에는 인터넷 연결이 필요하다.

임베딩 계산은 로컬 CPU에서 수행하며 Gemini API를 호출하지 않는다.



\## 현재 한계



\- 실습 문서 3개를 대상으로 검증했다.

\- 검색 임계값을 평가 데이터로 선정하지 않았다.

\- 긴 문서의 청크 분할은 아직 구현하지 않았다.

\- 모델의 입력 길이 제한으로 긴 문서는 잘릴 수 있다.

\- 문서 변경과 검색이 동시에 발생하는 운영 환경은 검증하지 않았다.

\- 역할은 CLI에서 지정하며 실제 사용자 인증은 아니다.

\- 일반 rag.py는 아직 기존 JSON 기반 키워드 검색을 사용한다.
